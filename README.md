# Task Manager

Трекер задач, призванный помочь пользователям повысить продуктивность в повседневной жизни. Ресурс позволяет создавать задачи, назначать им дату дедлайна и описание, удалять и изменять уже существующие задачи. Такая визуализация текущих планов способствует формированию у пользователя навыка эффективного тайм-менеджмента.

## Описание

Целью данной работы являлось закрепление навыков написания JavaScript скриптов и работы с локальной памятью браузера.

## Требования 

- Пакетный менеджер npm

## Установка
Для того, чтобы воспользоваться ресурсом достаточно перейти по ссылке на git-deploy в оригинальном репозитории. Если же по каким-либо причинам требуется запустить проект на своём вычислительном устройстве необходимо: 
1. Клонировать репозиторий
2. Установить зависимости с помощью следующей команды в консоли корня проекта:
```bash
npm install
```
3. Запустить локальный сервер:
```bash
npm run dev
```
4. Проект готов к использованию по ссылке, выведенной в консоль
