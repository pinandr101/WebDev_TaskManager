#TASK MANAGER
A simple web-project, created in educational purposes. Task manager, that can help you track daily goals.
#FEATURES
-Create task: Add new task with title, description and deadline date.
-Toggle status: Mark tasks as complete/incomplete with just a click.
-Delete task: Remove a task from your schedule.
-Access anytime: All tasks are saved in the browsers local storage. You can safely close the tab and return to the planning session later.
#Technology stack
-HTML5.
-CSS3.
-JavaScript.
#How to use
-Click the github-deploy link and use the website from any device.
-Clone repository for individual usage and ability to customize task manager.
